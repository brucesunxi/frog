# 真机页面检查与优化 · 2026-10-12

版本：**1.0.10 / versionCode 11**。设备：Samsung SM-G9860，Android 13。测试 APK 使用 Google 示例广告，发布 AAB 使用正式广告 ID。

## 已完成的优化

- 主菜单将玩法说明折叠，减少关卡列表上方占用；手机界面移除键盘操作说明。
- 准备、失败、关卡结算、好友邀请、好友房间、挑战结果和最终通关页采用固定标题、可滚动内容、固定底部操作区。
- 结算数据使用两列卡片，突出下一关并增加直接返回菜单；失败页突出重试按钮。
- 金币礼包改为单列信息列表，减少重复说明；商店不再显示 Android 不适用的网页奖励次数。
- 暂停页提供明确的声音开关文字，横屏采用紧凑按钮布局；金币不足提示框按钮至少 44 CSS px。
- 修复 Android `https://localhost` 访问网站 API 的预检问题，仅允许该原生来源，不开放任意跨域来源。钱包连接和好友房间创建已在真机恢复。
- 好友连接失败时显示明确错误及重试按钮；防止重复创建，以及离开页面后迟到的创建响应重新打开房间。API 请求增加超时。
- 打开系统分享页后不再声称邀请已经发送。

## 验证范围

12 个覆盖层页面分别检查纵屏和横屏，共 24 组记录。全部底部按钮在视口内、中心可命中、至少 44 CSS px 高，底部操作区没有横向溢出。测量记录见 [metrics.json](mobile-ui-audit-2026-10-12/metrics.json)。

| 页面 | 检查内容 |
| --- | --- |
| 主菜单 | 玩法展开、关卡列表滑动、底部操作保持固定 |
| 道具商店 | 卡片、余额、购买金币入口与返回 |
| 金币礼包 | 五档商品、独立滚动和状态反馈 |
| 关卡准备 | 说明、道具选择、开始及返回 |
| 暂停 | 继续、重开、商店、声音及菜单 |
| 关卡结算 | 星级、四项数据、下一关、准备道具及菜单 |
| 失败 | 可选激励复活、道具、重试及菜单 |
| 好友邀请 | 目标分数、规则、接受及返回 |
| 好友房间 | 真实创建、等待、连接错误与重试恢复 |
| 挑战结果 | 分数对比、分享/复制入口、重试及菜单 |
| 最终通关 | 总成绩、无尽模式及菜单入口 |
| 金币不足 | 说明、购买金币及返回 |

另检查纵横屏实际游戏画面：棋盘完整，方向按钮和暂停按钮可见；横屏方向按钮 44×44 CSS px，暂停按钮高 48 CSS px。Google 示例横幅独立显示，没有覆盖页面操作区。

通过真机 WebView 触控事件验证开始游戏、方向移动（列 9 → 8）、暂停、进入商店/金币礼包、返回继续游戏，以及菜单滑动。真实 API 创建好友房间成功；人为注入一次接口失败后，页面重试可恢复到真实房间。系统分享选择页可打开并取消，未发送邀请。

关卡结算、最终通关和好友结果页使用临时测试数据检查布局，不代表逐关通关或两台手机完成对战。测试期间屏蔽进度保存和自动同步，结束后重新启动应用加载真实存档。真实支付、两机同时开局和适用地区的同意表单仍需单独验证。
